# Platform Engineering

A production-style Platform Engineering project demonstrating modern DevOps and Infrastructure Engineering practices.

## Project Goal

The goal of this project is to design, build, automate, deploy, monitor, and secure a cloud-native platform using industry-standard tools and best practices.

Rather than demonstrating individual technologies in isolation, this repository shows how they work together to deliver reliable infrastructure and applications.

---

## Technologies

- Linux
- Git & GitHub
- Docker
- Docker Compose
- Terraform
- Kubernetes
- Helm
- GitHub Actions
- Prometheus
- Grafana
- Loki
- Alertmanager
